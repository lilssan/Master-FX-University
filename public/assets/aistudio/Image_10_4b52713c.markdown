## Brand & Style

The design system projects absolute market authority, institutional precision, and high-frequency execution discipline. Designed for an elite foreign exchange and trading education academy, it mirrors the density, low-latency clarity, and visual gravitas of tier-1 institutional trading desks. The aesthetic commands confidence through high-contrast legibility, rigorous information architecture, and controlled neon illumination against an obsidian black void.

The visual style merges institutional fintech precision with high-contrast performance design:
- **Surface Integrity:** Deep, noise-free obsidian layers (`#0B0B0B`, `#121214`) serve as the foundation, prioritizing prolonged focus during high-stress market sessions and live tape analysis.
- **Controlled Luminescence:** Vibrant crimson red accents (`#D32F2F`, `#FF334B`) are applied strategically to signal critical execution states, active setups, stop boundaries, and directional focus without visual fatigue.
- **Data-Dense Restraint:** Decorative flourishes are eliminated. Structural alignment, micro-borders, and pristine typography establish institutional legitimacy and premium curriculum value.

## Colors

The color palette is built for extreme contrast, dark-room ergonomics, and instantaneous semantic recognition:

- **Canvas & Surface Tiers:**
  - Base Background: `#0B0B0B` (pure dark obsidian backdrop).
  - Surface Card / Container Level 1: `#121214` (structured module base).
  - Surface Card / Container Level 2: `#1A1A1E` (nested rows, active inputs, popovers).
  - Surface Elevated / Modals: `#222228` (overlays and floating trade tickets).
- **Brand Accents & Signal Directives:**
  - Primary Red: `#D32F2F` (authoritative brand red, execution actions, risk markers).
  - Secondary Crimson: `#FF334B` (vibrant neon hover states, dynamic badges, live stream indicators).
  - Tertiary / Market Long: `#00E676` (profit, buy indicators, confirmed curriculum achievements).
- **Text & Editorial Hierarchy:**
  - Primary Text: `#FFFFFF` (crisp white, high readability for headlines, metrics, and values).
  - Secondary Text: `#94A3B8` (slate neutral for analytical subtext, curriculum metadata, labels).
  - Muted Text: `#64748B` (timestamps, inactive states, table column keys).
- **Borders & Rules:**
  - Default Border: `rgba(255, 255, 255, 0.08)` (subtle structural divider).
  - Accent / Focus Border: `rgba(211, 47, 47, 0.45)` (active module boundary, key trading callout).

## Typography

The typography uses Inter across all levels to maintain crisp geometric stability and neutral authority. High-volume tabular figures, rates, pip counters, and lesson module progress require uncompromised legibility across both compact mobile interfaces and multi-display desktop setups.

- **Tabular & Numeric Handling:** All price quotes, stop-loss ratios, win rates, and timestamps must enable tabular figure features (`font-feature-settings: "tnum" on, "cv05" on`) to avoid layout jitter during live updates.
- **Editorial vs. Metric Contrast:** Display headlines utilize tight negative tracking (`-0.02em` to `-0.03em`) and heavy weights (`700`, `800`) to anchor landing conversion sections and course headers. Small labels and metadata leverage uppercase transforms with deliberate letter spacing (`0.06em` to `0.08em`) to mimic terminal instruments.

## Layout & Spacing

The layout is engineered around a modular, responsive 12-column terminal grid designed for information density, live streaming setups, and course module hierarchies:

- **Desktop (1280px+):** 12-column layout with `2rem` gutters and `3.5rem` margins. Ideal for dual-column live charts, syllabus sidebars, and execution analytics.
- **Tablet (768px - 1279px):** 8-column layout with `1.5rem` gutters and `2rem` margins. Analytical side panels collapse into structured floating drawers.
- **Mobile (< 768px):** 4-column layout with `1rem` gutters and `1rem` canvas margins. Cards take full container width with stack-order prioritization (signals, core metrics, then course outlines).
- **Rhythm Principle:** Internal card padding is strictly uniform at `space-md` (16px) or `space-lg` (24px). Micro spacing (`space-xs` = 4px, `space-sm` = 8px) controls labels, price deltas, and badge iconography.

## Elevation & Depth

Visual hierarchy does not use diffuse multi-colored drop shadows. Depth is achieved through controlled obsidian surface tiers, razor-sharp 1px border lines, and directional crimson light bleeding:

- **Tier 0 (Base Ground):** `#0B0B0B` backdrop with no shadow.
- **Tier 1 (Surface Cards & Paneling):** `#121214` bounded by a crisp `1px solid rgba(255, 255, 255, 0.08)`.
- **Tier 2 (Active Modules & Focused Cards):** `#1A1A1E` with a hairline accent border `1px solid rgba(211, 47, 47, 0.35)` accompanied by an ambient crimson edge reflection (`box-shadow: 0 0 20px -6px rgba(211, 47, 47, 0.25)`).
- **Tier 3 (Floating Terminals, Live Modals, Dropdowns):** `#222228` elevated with an intense structural drop shadow (`box-shadow: 0 16px 40px rgba(0, 0, 0, 0.8), 0 0 0 1px rgba(255, 255, 255, 0.12)`).

## Shapes

The shape system is strictly technical and disciplined. Elements adhere to Level 1 (`0.25rem` / 4px base radius) to enforce a sharp, machine-tooled terminal feeling:

- **Buttons, Badges, & Small Inputs:** 4px (`0.25rem`) corner radius. Rounded forms are eliminated in favor of clean corner joints.
- **Cards & Data Tables:** 8px (`rounded-lg` / `0.5rem`) corner radius for outer module shells, maintaining a tight footprint while cleanly framing contents.
- **Modals & Canvas Containers:** 12px (`rounded-xl` / `0.75rem`) for high-level screen overlays.
- **Indicators & Live Status Nodes:** Exact circles (`border-radius: 9999px`) reserved strictly for pulsing live dots and market status pips.

## Components

### Buttons
- **Primary Execution Button:** Background `#D32F2F`, text `#FFFFFF`, font weight `600`, border-radius `4px`. Hover triggers transition to `#FF334B` with an ambient glow (`box-shadow: 0 0 16px rgba(255, 51, 75, 0.45)`). Active state scales slightly down (`transform: scale(0.98)`).
- **Secondary Terminal Button:** Background `transparent`, border `1px solid rgba(255, 255, 255, 0.2)`, text `#FFFFFF`. Hover state updates border to `rgba(255, 255, 255, 0.5)` with background `rgba(255, 255, 255, 0.04)`.
- **Ghost/Tertiary Action:** Borderless, text `#94A3B8`. Hover converts text to crisp `#FFFFFF`.

### Cards & Fintech Modules
- Built on `#121214` with a 1px border `rgba(255, 255, 255, 0.08)` and `8px` corner radius.
- **Active / Featured Course Card:** Border shifts to `rgba(211, 47, 47, 0.5)` with a subtle top hairline gradient highlighting the module header (`background: linear-gradient(180deg, rgba(211, 47, 47, 0.1) 0%, rgba(18, 18, 20, 0) 100%)`).

### Input Fields & Selectors
- Background `#1A1A1E`, border `1px solid rgba(255, 255, 255, 0.12)`, text `#FFFFFF`, placeholder `#64748B`, radius `4px`, padding `10px 14px`.
- **Focus State:** Border shifts to `#D32F2F` with a tight glowing contour (`box-shadow: 0 0 0 1px #D32F2F, 0 0 12px rgba(211, 47, 47, 0.25)`).

### Badges & Chips
- **Risk / Live Signal:** Solid or translucent crimson background (`rgba(211, 47, 47, 0.15)`), border `1px solid rgba(211, 47, 47, 0.4)`, text `#FF334B`, uppercase text tracking `0.06em`, font size `11px`.
- **Status / Tier Neutral:** Surface `#1A1A1E`, border `1px solid rgba(255, 255, 255, 0.1)`, text `#94A3B8`.

### Checkboxes & Radios
- Size `16px x 16px`, background `#1A1A1E`, border `1px solid rgba(255, 255, 255, 0.25)`, radius `3px` (checkbox) or circular (radio).
- Checked state fills with `#D32F2F` displaying a crisp white micro-check.

### Trading-Specific Components
- **Live Tape Ticker:** Continuous horizontal stream with background `#0B0B0B`, bordered bottom `1px solid rgba(255, 255, 255, 0.08)`. Currencies displayed in `#FFFFFF`, spreads in `#64748B`, and deltas formatted conditionally in `#00E676` or `#FF334B`.
- **Curriculum Step Tracker:** Vertical progression rail with `#1A1A1E` spine. Completed stages feature glowing crimson nodes (`#D32F2F`) with numerical completion meters set in `metric-mono`.
